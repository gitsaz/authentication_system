# Django Authentication System
#### A complete session-based authentication system built with Django, focusing on real-world authentication workflows and security best practices.

## Project Overview
#### **This project implements a traditional server-side authentication system using Django.**
It covers the full authentication lifecycle — from user registration to secure password reset via email.

## Tech Stack
- Python
- Django
- Django Authentication Framework
- Class Based Views (CBV)
- Bootstrap
- SQLite (default)

## Features
- User Registration
- Login using Username or Email
- Logout
- Password Change
- Password Reset via Email (Token-based)
- Custom Authentication Backend
- Secure Password Hashing
- Session-based Authentication
- Login protection using LoginRequiredMixin
- Responsive UI with Bootstrap
